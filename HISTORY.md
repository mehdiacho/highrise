# History

Repositories folded into this one. Each keeps its full commit history under
`history/<name>/`. To read those commits, find the "Fold <name>" commit and run
`git log <that commit>^2`. The original repositories were deleted on 2026-11-14; everything they held is in this one.

- **monopoly** (2025-09-17 to 2026-10-18): `history/monopoly/`. The original repository `monopoly` was deleted on 2026-11-14 once its history was here.
